# Glasstunnel 0.1.9

This public-beta update keeps Mac Screen sharing alive without a page refresh,
brings the Cursor desktop and Cursor Agent cards to the standard of the Claude
cards, and makes the Codex desktop card read the thread it shows.

## Fixed

- Mac Screen no longer goes black until the page is refreshed. The phone
  watches decoded and painted frames instead of trusting the video element,
  shows "Screen paused" when frames stop, and restarts the stream on its own
  with a growing wait. The Mac keeps one video sender per phone, repeats the
  last frame once a second while the screen is idle (protocol 0.2.3), restarts
  a capture that ScreenCaptureKit stops, and restarts on display changes,
  wake, and login. A stream now survives relay reconnects, lifecycle
  recoveries, and signaling drops, and the relay Worker closes a Mac socket
  that stopped pinging so phones stop seeing a dead Mac as online.
- The web app mounted two copies of every panel and only hid one with CSS;
  exactly one layout is mounted now.
- The Codex desktop card's model chip showed the global Codex default for
  every thread. It now shows the model and effort the selected thread actually
  runs, from the thread's own turn records and settings events.
- Current Codex threads write shell commands and patches as `custom_tool_call`
  records with list-shaped outputs. The card ignored the first and showed
  "no output" for the second; both now become titled rows (the command, the
  files a patch touches, "Update plan") with the exit code and wall time read
  from the output header, and "Show all N lines" fetches long outputs.
- Codex's machine-written context blocks no longer render as the user's own
  messages, attached images show as "[image]", prompts the app stored with
  Markdown escapes show as typed, and a turn stopped from the phone shows a
  "Stopped" divider.
- Linking the Codex card no longer stalls on "loading Codex context" for a
  Codex home with thousands of threads: the catalog scan opens only the
  newest rollouts.

## Added

- The Cursor Agent card streams each turn: the reply grows in place and every
  tool call becomes a row with its result, duration, and failure flag. The
  card lists the CLI's chats with their workspaces, resumes them, starts new
  ones, switches between ask and plan mode and between models from the phone,
  interrupts, and reads the chat's own store for history.
- The Cursor card reads Cursor 3.x's chat store, including tool calls and
  results as structured rows, takes live turn state from Cursor's hooks,
  switches chats from the phone and confirms the window shows them, refuses to
  type into a chat the window does not show, offers "New chat", and interrupts
  through the app's Stop control.
- Phone-driven Local Test Lab lanes for both Cursor cards and for the Codex
  desktop card, with evidence records in the support matrix.

## Changed

- The Mac pauses the JPEG screen fallback while every phone reports a live
  WebRTC track and resumes it the moment one stalls; it publishes its
  remote-app list only when it changed.
- Codex now ships inside ChatGPT.app. The Mac opts that shell into
  Accessibility before searching its window, finds the composer by its new
  placeholder ("Do anything"), and interrupts through the app's own Stop
  control before falling back to Escape.

## Support scope

- Mac Screen and scoped Terminal remain Supported.
- Claude desktop, Claude Code, Codex desktop, Codex CLI, Cursor, Cursor Agent,
  Gemini CLI, and OpenCode remain Preview.
- Generic window mirroring remains Experimental.
- The phone app and the Mac app need each other's 0.1.9 for the frame
  keepalive (protocol 0.2.3); older pairs keep working with the previous
  screen behaviour and the previous Codex rows.

## Install

```bash
brew tap datawithfurkan/glasstunnel https://github.com/datawithfurkan/glasstunnel
brew install --cask datawithfurkan/glasstunnel/glasstunnel
```

Existing Homebrew users can upgrade after refreshing the tap:

```bash
brew update
brew upgrade --cask datawithfurkan/glasstunnel/glasstunnel
```
