# Glasstunnel 0.1.9

This public-beta update brings the Codex desktop card level with the Claude
cards: it shows the model the thread really runs, reads Codex's current tool
records, and works with Codex inside the ChatGPT app.

## Fixed

- The Codex card's model chip showed the global Codex default for every thread.
  It now shows the model and effort the selected thread actually runs, read
  from the thread's own turn records and settings events.
- Codex's current threads write shell commands and patches as `custom_tool_call`
  records with list-shaped outputs. The card ignored the first and showed
  "no output" for the second; both now become titled rows (the command, the
  files a patch touches, "Update plan") with the exit code and wall time read
  from the output header, and "Show all N lines" fetches long outputs.
- Codex's machine-written context blocks (`<environment_context>`,
  `<recommended_plugins>`, skill text, image markers) no longer render as the
  user's own messages; attached images show as "[image]". Prompts the app
  stored with Markdown escapes show as typed.
- Linking the Codex card no longer stalls on "loading Codex context" for a
  Codex home with thousands of threads: the catalog scan opens only the newest
  rollouts.
- A Codex turn stopped from the phone shows a "Stopped" divider like the Claude
  cards.

## Changed

- Codex now ships inside ChatGPT.app. The Mac opts that shell into Accessibility
  before searching its window, finds the composer by its new placeholder ("Do
  anything"), and interrupts through the app's own Stop control before falling
  back to Escape.
- New lab lanes `pnpm lab:e2e:codex-desktop` and `pnpm lab:e2e:codex-desktop:safari`
  drive the Codex desktop card from a phone-sized browser against the real app;
  the support matrix records their evidence.

## Support scope

- Mac Screen and scoped Terminal remain Supported.
- Claude desktop, Claude Code, Codex desktop, Codex CLI, Cursor, Cursor Agent,
  Gemini CLI, and OpenCode remain Preview.
- Generic window mirroring remains Experimental.
- No protocol change: a 0.1.8 phone renders the new Codex rows from a 0.1.9 Mac.

## Install

```bash
brew tap datawithfurkan/glasstunnel https://github.com/datawithfurkan/glasstunnel
brew install --cask datawithfurkan/glasstunnel/glasstunnel
```

Existing Homebrew users can upgrade after refreshing the tap:

```bash
brew update
brew upgrade --cask datawithfurkan/glasstunnel/glasstunnel
```

The notarized DMG, the stable latest-download alias, and checksum files are
attached to this GitHub Release.
