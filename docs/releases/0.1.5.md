# Glasstunnel 0.1.5

This public-beta update restores compatibility with the current Codex desktop app
and improves the Mac app's maintenance and diagnostics experience.

## Fixed

- Codex projects use their real workspace names instead of raw `local-*` IDs.
- Selecting an existing Codex task from the web opens that exact desktop task.
- The mobile prompt composer becomes available when the selected Codex task is
  ready, while retaining guarded delivery to prevent prompts reaching another task.
- The signed Local Test Lab keeps a stable permission identity when Xcode signing
  certificates change.

## Added

- Privacy-safe Copy Diagnostics action in Mac Settings.
- Launch at Login control using the real macOS registration state.
- Installed version and build details with a link to official updates.

## Support scope

- Mac Screen and scoped Terminal remain Supported.
- Codex desktop and CLI remain Preview while broader upstream compatibility is
  verified.
- Other integration support tiers are unchanged.

## Install

```bash
brew tap datawithfurkan/glasstunnel https://github.com/datawithfurkan/glasstunnel
brew install --cask datawithfurkan/glasstunnel/glasstunnel
```

Existing Homebrew users can upgrade after refreshing the tap:

```bash
brew update
brew upgrade --cask datawithfurkan/glasstunnel/glasstunnel
```

The notarized DMG and its checksum file are attached to this GitHub Release.
