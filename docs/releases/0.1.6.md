# Glasstunnel 0.1.6

This public-beta patch fixes the Mac installer presentation and makes the public
website download button follow the latest release automatically.

## Fixed

- The DMG now includes an Applications drag target next to `Glasstunnel.app`.
- The packaged Mac app and PWA icons use the current Glasstunnel mark.
- Signing out from the Mac app now rotates the local access identity even when
  remote unlink succeeds.
- The public site no longer hardcodes a versioned DMG URL.

## Support scope

- Mac Screen and scoped Terminal remain Supported.
- Codex desktop and CLI remain Preview while broader upstream compatibility is
  verified.
- Other integration support tiers are unchanged.

## Install

```bash
brew tap datawithfurkan/glasstunnel https://github.com/datawithfurkan/glasstunnel
brew install --cask datawithfurkan/glasstunnel/glasstunnel
```

Existing Homebrew users can upgrade after refreshing the tap:

```bash
brew update
brew upgrade --cask datawithfurkan/glasstunnel/glasstunnel
```

The notarized DMG, the stable latest-download alias, and checksum files are
attached to this GitHub Release.
