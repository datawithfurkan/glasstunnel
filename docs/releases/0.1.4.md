# Glasstunnel 0.1.4

Glasstunnel's first public beta lets you reach a Mac from a signed-in mobile
browser, share its screen, and use a scoped remote Terminal. The project is
open source under Apache 2.0.

## Supported

- Mac Screen start, stop, restart, and remote input.
- Scoped Terminal sessions, including create, rename, close, and interrupt.
- Account linking between the Mac app and signed-in web devices.

## Preview

- Codex desktop and CLI workflows.
- Cursor desktop and Agent CLI workflows.
- Gemini CLI workflows.
- OpenCode desktop and CLI workflows.

Preview integrations are useful but can change when their upstream apps change.

## Experimental

- Claude Code integration.
- Generic window mirroring for unsupported apps.

## Known limitations

- Glasstunnel currently requires macOS 13 or later.
- The Mac must be awake, online, and running Glasstunnel for remote access.
- Screen Recording and Accessibility permission changes may require relaunching
  the Mac app when macOS asks for it.
- Preview and Experimental integrations can require their native app or CLI to be
  installed and authenticated on the Mac.

## Install

```bash
brew install --cask glasstunnel
```

The notarized DMG and its SHA-256 checksum are attached to this GitHub Release.
