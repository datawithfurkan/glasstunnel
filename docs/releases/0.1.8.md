# Glasstunnel 0.1.8

This public-beta update makes agent transcripts readable on the phone and fixes
a stuck "working" state after an interrupt.

## Added

- Chat-style cards (Claude, Codex, Cursor) render transcripts for reading:
  replies as Markdown, tool calls folded into one-line rows grouped per turn
  with their output behind a tap, events as thin dividers, and a Focus/Full
  switch remembered on the phone.
- The Mac now names each tool call (the command, the file, the pattern), pairs
  results with their calls, and sends a 12-line preview with the full line
  count, duration, and failure flag; the full output is fetched on request
  from the row's "Show all" button. The Codex card shows its shell calls the
  same way.
- Running rows show elapsed time, unified diffs are coloured, terminal colour
  codes are stripped, and output and code blocks have a Copy button. New
  messages no longer pull the view away while you are reading earlier ones.

## Fixed

- The Claude cards no longer flip from "Stopped" back to "Claude is working"
  when the app files the interrupted tool's result after an interrupt.

## Support scope

- Mac Screen and scoped Terminal remain Supported.
- Claude desktop, Claude Code, Codex desktop, Codex CLI, Cursor, Cursor Agent,
  Gemini CLI, and OpenCode remain Preview.
- Generic window mirroring remains Experimental.
- The phone app and the Mac app need each other's 0.1.8 for the new transcript
  rows; older pairs keep working with the previous rendering.

## Install

```bash
brew tap datawithfurkan/glasstunnel https://github.com/datawithfurkan/glasstunnel
brew install --cask datawithfurkan/glasstunnel/glasstunnel
```

Existing Homebrew users can upgrade after refreshing the tap:

```bash
brew update
brew upgrade --cask datawithfurkan/glasstunnel/glasstunnel
```
