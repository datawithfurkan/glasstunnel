# Glasstunnel 0.1.13

This public-beta update brings the Mac side of the October security review.
The web and server fixes from the same review are already live and need no
update: the web app connects only to its own signaling service, a Mac code
that arrives in a link takes a tap on **Add**, email sign-in slows down after
repeated wrong passwords, and the signaling service refuses oversized or
malformed requests.

## Security

- The hook commands Glasstunnel installs into Claude Code and Cursor run Python
  in isolated mode, so a `json.py` or similar file in a project folder is never
  run. They update themselves when the app starts.
- The installed app ignores server-address, device-key, and device-list
  overrides from the environment or saved settings, so other software on the
  Mac cannot redirect it or the code it opens in your browser.
- Relay commands are accepted only from browsers this Mac knows.
- An app turned off in the Mac app (Terminal, Mac Screen, an agent) can no
  longer be turned back on from a browser; the browser says it is turned off on
  the Mac.
- The Screen Recording and Accessibility prompts describe what Glasstunnel does
  with them.

## Fixed

- The Mac's sign-in screen says to choose **Add** in the browser after signing
  in.

## Support scope

- Mac Screen and scoped Terminal remain Supported.
- Claude desktop, Claude Code, Codex desktop, Codex CLI, Cursor, Cursor Agent,
  Gemini CLI, and OpenCode remain Preview.
- Generic window mirroring remains Experimental.
- Protocol 0.2.3 is unchanged.

## Install

On 0.1.11 or later, choose **Glasstunnel > Check for Updates…** and click
**Install Update**.

```bash
brew tap datawithfurkan/glasstunnel https://github.com/datawithfurkan/glasstunnel
brew install --cask datawithfurkan/glasstunnel/glasstunnel
```

Existing Homebrew users can upgrade after refreshing the tap:

```bash
brew update
brew upgrade --cask --greedy datawithfurkan/glasstunnel/glasstunnel
```

The notarized DMG, the stable latest-download alias, the checksum files, and the
signed update feed (`appcast.xml`) are attached to this GitHub Release.
