# Glasstunnel 0.1.7

This public-beta update adds Claude Code support in Preview: a new "Claude" card
for sessions hosted by the Claude desktop app, and a hardened Claude Code CLI
card. It also fixes a relay authentication race and a Mac Screen reconnect bug.

## Added

- "Claude" card for Claude Code sessions hosted by the Claude desktop app:
  session discovery and switching, prompts delivered into the real window through
  Accessibility, Allow/Deny for permission prompts, answers to Claude's questions,
  interrupt, and a read-only model display.
- The Claude Code CLI card offers its session switcher on the phone, turns the
  workspace-trust dialog into a decision on the phone, and starts a fresh session
  when the one it tried to resume is held by another process.
- Decisions raised by CLI cards (Codex's update prompt, Claude Code's trust check)
  render their choices on the phone.

## Fixed

- Relay and signaling connections no longer fail authentication when the socket
  closes, or a quick reconnect replaces it, while the service is still checking
  the account; a dead connection can no longer block the next one.
- Mac Screen no longer reports "Screen unavailable" when the phone announces
  itself twice in quick succession, for example while switching quality.
- CLI cards no longer drop terminal output at read boundaries and keep what a
  process prints as it exits.

## Support scope

- Mac Screen and scoped Terminal remain Supported.
- Claude desktop and Claude Code join Codex desktop, Codex CLI, Cursor, Cursor
  Agent, Gemini CLI, and OpenCode as Preview. The Claude cards have recorded
  phone-driven runs against the real app and CLI on mobile Chromium and WebKit;
  the desktop card relies on Accessibility because the app's deep links are
  gated off, and needs a Code session visible in the app.
- Generic window mirroring remains Experimental.

## Install

```bash
brew tap datawithfurkan/glasstunnel https://github.com/datawithfurkan/glasstunnel
brew install --cask datawithfurkan/glasstunnel/glasstunnel
```

Existing Homebrew users can upgrade after refreshing the tap:

```bash
brew update
brew upgrade --cask datawithfurkan/glasstunnel/glasstunnel
```
