# Glasstunnel 0.1.11

This public-beta update is the last one you install by hand: the Mac app now
updates itself. It also gains a menu bar icon and keeps the Mac online when its
window closes, an Open on Phone button, and the Mac side of account-wide
access and Mac management.

## Updates

- **Glasstunnel > Check for Updates…** (also in **Settings > Updates**) shows
  what is new and installs the new version with one click, then relaunches.
  The app checks once a day; the daily check and fully automatic installs can
  be switched in Settings.
- Updates are verified before they are opened: the update feed and every DMG
  are signed with the project's EdDSA update key, on top of Developer ID
  signing and notarization. A feed or DMG that does not match the key is
  refused.
- **Settings…** in the Glasstunnel menu (⌘,) opens the app's Settings page.
- Homebrew users can keep using `brew upgrade --cask --greedy`; the cask now
  declares `auto_updates`.

## Menu bar

- A menu bar icon shows whether the Mac is online, the Screen Recording and
  Accessibility permissions, Read-only mode, Keep Mac awake, and how many
  devices have access, with Open Workspace, Open Web App, Open Access,
  Check for Updates…, and Quit Glasstunnel. The icon dims while the Mac is
  offline or reconnecting.
- Closing the window no longer quits Glasstunnel, so the phone keeps its Mac.
  The Dock icon hides until the window opens again. **Quit Glasstunnel** takes
  the Mac offline.

## Getting to the web app

- The Mac app has an **Open on Phone** button in its header: a QR code for
  app.glasstunnel.io, the account to sign in with, and the Mac to choose, with
  Open in Browser and Copy Link. The Access page has the same QR code, and the
  Mac's sign-in screen names signing in on the phone as the next step.
- glasstunnel.io has a **Sign in** button, and the web app's sign-in screen
  links to installing the Mac app. These were already live.

## Access and Your Macs

- Signed in means connected: any browser signed in to your account reaches
  every Mac on it. On the Mac, "Revoke Access" is now **Sign Out Browser** and
  "Remove Device" is **Sign Out and Remove**; they sign that browser out of the
  account instead of leaving a silent, permanent block.
- The web app can rename a Mac, show its details, and remove it from the
  account. A removed Mac says so and ends its phone sessions. The Mac shows the
  name the account uses for it and reports its app version.

## Support scope

- Mac Screen and scoped Terminal remain Supported.
- Claude desktop, Claude Code, Codex desktop, Codex CLI, Cursor, Cursor Agent,
  Gemini CLI, and OpenCode remain Preview; their recorded evidence is
  unchanged from 0.1.10.
- Generic window mirroring remains Experimental.
- Protocol 0.2.3 is unchanged.

## Install

```bash
brew tap datawithfurkan/glasstunnel https://github.com/datawithfurkan/glasstunnel
brew install --cask datawithfurkan/glasstunnel/glasstunnel
```

Existing Homebrew users can upgrade after refreshing the tap:

```bash
brew update
brew upgrade --cask datawithfurkan/glasstunnel/glasstunnel
```

Everyone on 0.1.10 or earlier installs this version by hand once; later
versions install from inside the app. The notarized DMG, the stable
latest-download alias, the checksum files, and the signed update feed
(`appcast.xml`) are attached to this GitHub Release.
