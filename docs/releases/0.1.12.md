# Glasstunnel 0.1.12

This public-beta update gives the download a designed installer window, and it
is the first version that Macs on 0.1.11 install from inside the app.

## Installing

- The disk image opens a designed installer window: the Glasstunnel app and the
  Applications folder sit on artwork with an arrow between them, "Drag
  Glasstunnel into Applications", and the next step (sign in on your phone at
  app.glasstunnel.io). The disk shows the Glasstunnel icon.
- On 0.1.11, choose **Glasstunnel > Check for Updates…** (or wait for the daily
  check) and click **Install Update**; the app installs 0.1.12 and relaunches.
  Updates installed this way skip the installer window.

## Support scope

- Mac Screen and scoped Terminal remain Supported.
- Claude desktop, Claude Code, Codex desktop, Codex CLI, Cursor, Cursor Agent,
  Gemini CLI, and OpenCode remain Preview.
- Generic window mirroring remains Experimental.
- Protocol 0.2.3 is unchanged. The app is unchanged from 0.1.11 apart from its
  version; only the disk image around it is new.

## Install

```bash
brew tap datawithfurkan/glasstunnel https://github.com/datawithfurkan/glasstunnel
brew install --cask datawithfurkan/glasstunnel/glasstunnel
```

Existing Homebrew users can upgrade after refreshing the tap:

```bash
brew update
brew upgrade --cask --greedy datawithfurkan/glasstunnel/glasstunnel
```

The notarized DMG, the stable latest-download alias, the checksum files, and the
signed update feed (`appcast.xml`) are attached to this GitHub Release.
